# Week 2: Advanced JavaScript, Modules, and Collections

This folder contains assignments for the second week of training, focusing on modular programming, copying techniques, working with dates, and using modern JavaScript collections.

## Topics Covered

*   **E-ComShoppingCartSys-modules**: A modular approach to building a basic E-commerce shopping cart system. Demonstrates breaking down functionality into separate, manageable files.
*   **ToDo-modules**: A modular implementation of a ToDo application, separating concerns like data management and presentation logic.
*   **copyTypes**: Exercises exploring the differences between deep copies and shallow copies in JavaScript and how to properly clone objects and arrays.
*   **dateOperations**: Practice with JavaScript Date objects, including parsing, formatting, and manipulating dates and times.
*   **onlineLearningPlatform-collections**: Working with specialized data structures such as `Map` and `Set` to manage collections of data efficiently.

## How to Run

Navigate to the specific assignment folder and use Node.js to run the main script.

```bash
node index.js
```
*(Replace `index.js` with the entry point file name of the specific assignment).*
