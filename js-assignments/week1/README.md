# Week 1: JavaScript Basics and Core Operations

This folder contains the assignments and practice code for the first week of training. The focus is on fundamental JavaScript concepts and operations.

## Topics Covered

*   **arrayAdvOperations**: Scripts demonstrating advanced operations on arrays, such as `map`, `filter`, `reduce`, and other higher-order functions.
*   **arrayOperations**: Basic array manipulation techniques including adding, removing, and accessing elements.
*   **controlStatements**: Examples of conditional statements (`if`, `else`, `switch`) and loops (`for`, `while`) used to control the flow of execution.
*   **objectOperations**: Practical exercises working with JavaScript objects, including creation, property access, and modification.
*   **operators.js**: A script showcasing the usage of various JavaScript operators (arithmetic, comparison, logical, etc.).

## How to Run

To execute any of the scripts, ensure you have Node.js installed on your system. Run a specific file using the following command in your terminal:

```bash
node filename.js
```
