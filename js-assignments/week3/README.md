# Week 3: Introduction to Backend and Databases

This folder contains assignments for the third week of training, marking the transition into backend development and database integration.

## Topics Covered

*   **1-First-Backend**: The foundation of backend development. This includes setting up a basic Node.js and Express.js server, defining routes, and handling fundamental HTTP requests and responses.
*   **Backend-With-DataBase**: Integrating a database into the backend application. This covers connecting a Node.js server to MongoDB using Mongoose, defining schemas, and performing basic CRUD operations.
*   **mongoDbCommands.txt**: A text file serving as a reference guide for essential MongoDB shell commands used for managing databases, collections, and documents directly.

## Prerequisites

To run these backend projects, you will need:
1.  Node.js installed.
2.  MongoDB installed and running locally, or access to a MongoDB Atlas cluster.

## How to Run

For the backend applications, navigate into the project directory and install the necessary dependencies before starting the server.

```bash
cd <project-folder-name>
npm install
node server.js
```
*(Ensure you configure any required environment variables, like the MongoDB URI, if applicable).*
